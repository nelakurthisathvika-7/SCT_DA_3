# Employee Attrition Analysis Dashboard

## Project Overview
This project analyzes employee attrition using the IBM HR Analytics Employee Attrition dataset and Microsoft Power BI.

## Objectives
- Analyze employee attrition patterns.
- Calculate total employees, employees who left, employees who stayed, and attrition rate.
- Compare attrition by department, age group, and overtime status.
- Provide interactive filters for exploring employee attrition.

## Tools Used
- Microsoft Power BI
- DAX
- IBM HR Analytics Employee Attrition dataset

## Key Metrics
- Total Employees: 1,470
- Employees Left: 237
- Employees Stayed: 1,233
- Overall Attrition Rate: 16.1%

## Files
- `Employee_Attrition_Analysis.pbix` — Power BI dashboard.
- `dashboard_screenshot.png` — Dashboard preview.

## Conclusion
The dashboard helps explore employee attrition patterns and supports further investigation into employee retention.
